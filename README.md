# Password Strength Checker

## Project Description
This is a beginner-friendly Python program that checks a password against five basic criteria.

## Features
- Checks whether the password contains at least 8 characters.
- Checks for uppercase letters.
- Checks for lowercase letters.
- Checks for numbers.
- Checks for special characters.
- Displays the results and a simple rating.

## Requirements
- Python 3

## How to Run
1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run the following command:

   `python password_checker.py`

## Purpose
This project was created for learning Python programming and basic cybersecurity concepts.

## Disclaimer
This program provides basic educational checks and does not guarantee password security.
